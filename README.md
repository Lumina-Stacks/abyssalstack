# Abyssal Stack — Distribution & Release Hub

Official distribution repository for **Abyssal Stack**, a modern, lightweight, isolated development environment for PHP and MySQL/MariaDB on Windows.

- **Source Code (Private)**: [Lumina-Stacks/abyssal-stack](https://github.com/Lumina-Stacks/abyssal-stack)
- **Website & Documentation**: [abyssalstack.com](https://abyssalstack.com)

---

## Files in this Repository

- **`manifest.json`**: Dynamic runtime catalog (PHP 8.1–8.5, MariaDB 10.11/11.4, Caddy, phpMyAdmin).
- **`update.json`**: Official auto-updater feed for the Abyssal Stack desktop application.
- **Releases**: Download standalone portable binaries and `.msi` installers under [GitHub Releases](../../releases).
